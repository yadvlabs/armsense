# Branding, naming and attribution

armsense is derived from the pfSense® Community Edition source code and
must not look like, or be confused with, pfSense software or a Netgate
product. This page records what the build changes, what it deliberately
keeps, and why.

## What is renamed or replaced

Applied by `build/src/rename-src.sh` and `build/src/debrand-src.sh` to the
GUI/backend tree, and by `build/ports/prepare-ports.sh` to the ports tree.

* Product identity: `product_name`, `product_label` and the package prefix
  (`armsense-pkg-*`), the `/etc/armsense-rc` family of scripts, the
  `/usr/local/share/armsense` and `/usr/local/armsense` trees, the PHP
  extension (`armsense.so`), and every port and package name.
* Logo and icons: the GUI header logo, favicons, Android/Windows tiles,
  Apple touch icons and the Safari pinned-tab mask come from
  `build/branding/` (generated by `branding/make-logo.py`). The mark is a
  monochrome badge: a disc with a shield and a chip.
* Console and boot loader: ASCII wordmark at boot, the loader brand and
  logo, and the console banner ("Device ID" instead of the vendor's device
  ID label).
* Installer: title, prompts, ZFS pool name and the license screen (now the
  Apache 2.0 notice with attribution).
* GUI text: welcome and completion pages of the setup wizard, the traffic
  shaper wizard titles, the footer credit, the nginx 404/50x pages, the
  captive portal default page, theme names (`armsense`, `armsense-dark`,
  ...), help-text mentions of the product, the copyright/license dialog.
* Help menu: "armsense Project", Documentation, User Forum, pfSense Book
  and FreeBSD Handbook remain; "Paid Support", "Upgrade to pfSense Plus"
  and System → Register are removed.
* Default configuration: hostname `armsense`, dashboard without the vendor
  support widget, theme `armsense.css`, admin password `armsense`.

## Vendor services that are disabled or replaced

* Copyright-notice download (`copyget.inc`): no longer contacts the vendor;
  the notice is static.
* Vendor services/support dashboard widget and the Plus registration page:
  removed.
* Repository client (`armsense-repoc`): a local stand-in that installs the
  static repository definitions shipped by `armsense-repo`.
* Vendor package-signing fingerprints and the vendor CA certificate shipped
  under the product's keys and ssl directories: removed.
* Unique device ID (`gnid`): a local stand-in derived from the kernel host
  UUID. It is only used locally and in the User-Agent of package requests
  (can be turned off under System → Advanced → Miscellaneous).

## What is kept, on purpose

* Source file headers: the Apache License requires the original copyright
  notices to stay in every file. They are comments and never shown in the
  product.
* Attribution: the copyright/license dialog (`copynotice.inc`), the
  installer license screen, `NOTICE` and `README.md` state that armsense is
  derived from pfSense CE software and that pfSense is a trademark of
  Electric Sheep Fencing, LLC. This is required by the license and is
  factual, not branding.
* Documentation links: the Help menu and the setup wizard link to the
  pfSense documentation, forum and book, because that documentation
  applies to armsense.
* Internal identifiers that the code depends on and that users never see:
  PHP function names (`pfSense_*`), the `pfSense\` PHP namespace, the
  gettext domain and translation catalogs, RADIUS vendor attribute names
  (`pfSense-Bandwidth-Max-*`), the `<pfsense>` root element of `config.xml`
  (so pfSense configuration backups still import), `pfSense.js` and
  `pfSenseHelpers.js`, upstream bug tracker links in comments.
* Hardware descriptions of Netgate appliances in `system.inc`: only shown
  when running on that hardware.
* Features that talk to the vendor's cloud if the user enables them:
  Auto Config Backup (`services_acb_settings.php`, uploads encrypted
  backups to the vendor's ACB service) and the crash reporter. They are
  off by default; removing or re-pointing them is a possible follow-up.

## Checking a build

After `rename-src.sh` the script prints any remaining user-visible
"Netgate" mentions outside the allowed set. For a running image:

    grep -o -i -E '.{40}(netgate|pfsense).{40}' <saved GUI pages> \
      | grep -v -E 'docs.netgate.com|redirects.netgate.com|pfsense/en/latest'

should only match the attribution text of the license dialog.
