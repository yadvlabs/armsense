armsense v0.1.0 — first development snapshot

Highly experimental: this release may or may not work, has not been
audited and is not fit for production use. It is provided "as is", without
warranty of any kind; use it at your own risk.

This tag versions the build tooling, branding and documentation that
produce armsense, a firewall/router distribution for arm64 derived from the
pfSense® Community Edition code base (Apache License 2.0). It is a
development snapshot: suitable for trying out in a virtual machine, not for
production use.

What works

* Full build pipeline on a FreeBSD 16.0-CURRENT arm64 host: world and
  kernel, 221 packages via poudriere, core packages, UEFI installer ISO,
  bootable qcow2/raw disk image (`build/`).
* The disk image boots on QEMU/KVM (UEFI), configures WAN (first virtio NIC,
  DHCP) and LAN (second, 192.168.1.1), serves the web GUI and installs
  package updates from the armsense repositories.
* Product rebranded end to end: name, packages, logo and icons, console and
  loader, installer, wizard, themes; vendor services disabled.

Defaults

* Login `admin` / `armsense`, hostname `armsense`, serial console enabled.

Known limitations

* Package repositories are unsigned and point at a development server.
* PPPoE uses the mpd5 path; the upstream in-kernel driver is not available.
* Stand-ins replace the upstream repository client and unique-ID tool;
  Kea is the stock version.
* Raspberry Pi images are not produced yet.

Images are built on the FreeBSD build VM and attached to this release
separately (`buildvm/publish-release.sh`).
